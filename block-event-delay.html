4 - Block Event Delay

Block Event Delay is not a complete substitute for tilesets, but it can significantly reduce the required length of tilesets and compact repetetive systems. It is based on a behavior of piston push lists which repeats a given global order for multiple components. A smaller tileset can set a ‘template’ ordering for a few components, then BED can trivially ‘repeat’ that order for a subsequent set of components.

prefix | BED -->
    00 | A D G J ...
    01 | B E H K ...
    10 | C F I L ...

Note:

This isn’t exactly correct because the pistons take 2gt to extend and retract, but it correctly explains the update order of the observers
